Git使用时弹出用户选择弹窗

Created2026-05-06|Updated2026-05-06|伊地知虹夏的备忘录
|Post Views:

问题描述

在使用Git提交或者拉取时，总是先弹出让选择一个用户，想去掉这个弹窗，不要再弹了

解决办法

彻底删除 Windows 凭据

  • 打开“控制面板” → “用户账户” → “凭据管理器” → “Windows 凭据”
  • 在“普通凭据”列表中，找到所有与 git 相关的条目，例如 git:https://github.com、git:https://gitee.com 等，然后逐一展开并点击“删除”。

精确指定

如果你的远程仓库地址是 HTTPS 协议，可以在 URL 中直接带上用户名，这样 Git 的凭证匹配会更精确，例如：
