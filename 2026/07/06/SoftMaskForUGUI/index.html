SoftMaskForUGUI 源码分析与实现原理

Created2026-07-06|Updated2026-07-07|UnityUGUI
|Post Views:

SoftMaskForUGUI 的核心设计理念是 离屏渲染（RenderTexture）+ 自定义 Shader，通过在 CPU 端手动构建渲染指令，将遮罩图形绘制到一张中间纹理上，再将该纹理作为独立的遮罩参数传递给子元素的 Shader，从而实现边缘平滑的遮罩效果。

一、核心组件与生命周期

1. UpdateParentSoftMask

  • 在发生 MaterialDirty 或 OnTransformParentChanged 时被调用
  • 用于更新当前 SoftMask 组件所持有的 直接上级 SoftMask 引用
  • 每个 SoftMask 都会持有一个指向其父级 SoftMask 的引用（如果有的话），形成一条 自下而上的链式引用关系

2. RenderSoftMaskBuffer

  • 在 Canvas 开始渲染时被调用
  • 将自身以及所有父级 SoftMask 绘制到一张 RenderTexture 上
  • RenderTexture 的尺寸受组件中的 降采样率（Desampling Rate） 控制，降采样率越高，渲染性能越好，边缘精细度略有下降

二、嵌套 SoftMask 的叠加渲染

当存在多层 SoftMask 嵌套时（例如 A → B → C，其中 C 是 A 和 B 的子级），渲染结果遵循 “后渲染覆盖先渲染” 的叠加规则：

层级 渲染范围 最终结果中的内容
最外层 A 仅 A 自身 仅 A 的遮罩图形
中间层 B A + B 的叠加 B 覆盖在 A 之上
最内层 C A + B + C 的叠加 C 覆盖在 B 之上，再覆盖在 A 之上

渲染结果的两种使用方式

  • 在父级 SoftMask 中：渲染结果仅作为临时中间纹理，用于继续叠加子级遮罩。
  • 在最内层 SoftMask（叶子节点）中：渲染结果作为 最终遮罩贴图，传递给子 SoftMaskable 元素，用于实际渲染。

该插件最多支持 4 层 SoftMask 嵌套，超出部分将被忽略。

三、子物体（SoftMaskable）的渲染流程

SoftMaskable 组件挂载在 SoftMask 下的子 UI 元素上（如 Image、RawImage、Text 等），它通过以下机制参与渲染：

  1. 实现 IMaterialModifier 接口：通过 GetModifiedMaterial 方法，拦截并替换自身的渲染材质。
  2. 材质替换：GetModifiedMaterial 会返回一个 自定义材质，该材质：
    • 保留子元素原有的 mainTexture（即 Image 的 Sprite 纹理或 RawImage 的纹理）
    • 额外接收父级 SoftMask 的 RenderTexture 作为遮罩纹理（通常绑定到 _SoftMaskTex 等 Shader 属性）
    • 绑定父级 SoftMask 的遮罩参数（如软边缘范围、透明度阈值等）
  3. 最终渲染：修改后的材质经由 CanvasRenderer 提交给 GPU。在片元着色器中，对 _SoftMaskTex 进行采样，结合主纹理的颜色，根据遮罩图形的透明度梯度计算出最终的 Alpha 值，实现边缘平滑效果。

四、实现细节与优化

SoftMaskForUGUI 在实际实现中，还包含以下值得关注的细节：

1. 帧缓存（FrameCache）

  • 用于防止同一帧内对同一数据重复创建或重复调用
  • 减少不必要的 CPU 和 GPU 开销，提升性能

2. VR 立体视角支持

  • 插件对 VR 环境下的双目渲染做了适配
  • 确保在立体渲染模式下遮罩效果正确

3. UGUI 脏标记接入

  • SoftMask 和 SoftMaskable 都接入了 UGUI 的脏标记管理系统
  • 仅在必要时（如材质变化、尺寸变化、父级变化）才触发重建，避免每帧全量更新

4. 扩展方法

  • 对 Graphic、Canvas、RectTransform 等常用组件提供了便捷扩展方法
  • 用于快速获取父级 SoftMask、检查是否处于遮罩范围等

五、总结

核心概念 关键点
实现方案 离屏渲染（RenderTexture）+ 自定义 Shader
核心组件 UpdateParentSoftMask（更新父级引用）、RenderSoftMaskBuffer（执行离屏渲染）
子元素渲染方式 保留自身 mainTexture，额外接收 RenderTexture 作为遮罩纹理
嵌套支持 最多支持 4 层嵌套，渲染结果逐层叠加
优化手段 降采样率、帧缓存、脏标记管理、VR 适配
额外开销 RenderTexture 内存 + 离屏渲染 DrawCall + 材质切换

📝 写在最后
SoftMaskForUGUI 通过对 UGUI 渲染管线的深度定制，在原生 Mask 的模板测试基础上，引入了离屏渲染和自定义 Shader 机制，实现了边缘平滑的遮罩效果。
